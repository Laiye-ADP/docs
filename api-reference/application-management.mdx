ADP 以应用为单位组织文档处理能力。你可以直接使用系统提供的开箱即用应用，也可以根据业务需求创建自定义抽取应用或工作流应用。

<Columns cols={2}>
  <Card title="模板应用" icon="sparkles">
    针对常见文档类型与文档处理场景预置抽取字段和业务规则，可直接添加为我的应用后使用。
  </Card>
  <Card title="自定义应用" icon="sliders-horizontal">
    针对模板未提供的其他任何场景，都可以创建我的应用后进行使用。
  </Card>
</Columns>

<Note>
  本分组中的“创建抽取应用”接口用于创建自定义抽取应用。开箱即用应用由系统提供；工作流应用在 ADP 中创建，并通过“工作流”分组中的接口查询和运行。
</Note>

## 模板应用

开箱即用应用覆盖文档解析、票据、订单和常用卡证等场景。下表展示当前系统预置目录中的应用名称、标签和用途。

<Info>
  不同站点、账号权限和产品版本可用的应用可能不同。请以“查询应用列表”接口的实际结果为准；查询全部开箱即用应用时，设置 `app_type=0`，并且不传 `ai_function`。
</Info>

| 应用名称 | 应用类型 | 应用标签 | 应用描述 |
| --- | --- | --- | --- |
| 文档解析 | 抽取 | 文档解析、图片提取、OCR、结构化解析、批量解析 | 识别文档或图片中的文字、版面与阅读顺序，返回结构化解析结果。 |
| 海外发票和收据（标准版） | 抽取 | 发票、收据 | 提取海外发票、收据和小票中的基础信息、金额、税务及商品明细。 |
| 海外发票和收据（高速版） | 抽取 | 发票、收据、全球发票、高准确度、高速抽取 | 面向国际通用的海外发票和收据，适合对处理效率有要求的字段抽取场景。 |
| 海外发票和收据（东南亚版） | 抽取 | 发票、收据、票据、东南亚发票、高准确度、高速抽取 | 面向东南亚发票和收据，增加付款方国家、预扣税及行级预扣税字段。 |
| 采购订单 | 抽取 | 订单、电商物流、出入库管理、信息提取 | 提取多语种采购订单中的订单、买卖双方、交付和商品明细信息。 |
| 国内通用多票据 | 抽取 | 国内通用多票据、多票据识别、财务报销、全票种识别、发票组件、发票验真 | 识别多类国内票据并返回对应业务字段，适用于报销和财务录入。 |
| 身份证 | 抽取 | 身份证、大陆居民身份证、身份凭证、个人证件、信息提取 | 识别居民身份证正反面的姓名、证件号码、住址、有效期等信息。 |
| 银行卡 | 抽取 | 银行卡、银行服务、支付工具、个人证件、信息提取 | 识别银行卡号、有效期、发卡机构和卡片类型。 |
| 车辆合格证 | 抽取 | 车辆合格证、车辆凭证、车辆管理、证件、信息提取 | 提取车辆型号、发动机号、车辆识别代号和制造日期等信息。 |
| 开户许可证 | 抽取 | 开户许可证、银行凭证、企业开户、金融证件、信息提取 | 提取核准号、编号、存款人、开户银行和账号等信息。 |
| 驾驶证 | 抽取 | 驾驶证、机动车驾照、交通管理、证件、信息提取 | 提取驾驶证号、姓名、准驾车型、有效期和签发机构等信息。 |
| 营业执照 | 抽取 | 营业执照、企业资质、工商凭证、商业证件、信息提取 | 提取统一社会信用代码、企业名称、类型、经营范围和登记信息。 |
| 护照-中国 | 抽取 | 护照-中国、旅行凭证、出入境证件、个人证件、信息提取 | 提取护照号码、姓名、国籍、出生日期、签发信息和有效期。 |
| 行驶证 | 抽取 | 行驶证、机动车行驶证、交通管理、证件、信息提取 | 提取号牌号码、车辆类型、所有人、车辆识别代号和登记日期等信息。 |
| 组织机构代码证 | 抽取 | 组织机构代码证、商业证件、证件、信息提取 | 提取组织机构代码、机构名称、机构类型、地址和有效期等信息。 |
| 户口本 | 抽取 | 户口本、户籍凭证、人口管理、家庭证件、信息提取 | 提取户主页和成员页中的户号、姓名、籍贯、身份证号及成员关系。 |
| 港澳通行证 | 抽取 | 港澳通行证、旅行凭证、出入境证件、个人证件、信息提取 | 提取证件号码、姓名、签发地、有效期和签发机关等信息。 |

## 常用管理操作

| 操作 | 接口 |
| --- | --- |
| 创建自定义抽取应用 | `POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/create` |
| 查询应用列表 | `GET /open/agentic_doc_processor/{tenant_name}/v1/app-list` |
| 修改或删除应用 | `POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/update`、`POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/delete` |
| 查询或删除配置版本 | `POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/config`、`POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/version/delete` |
