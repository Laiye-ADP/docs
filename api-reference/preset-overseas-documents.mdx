## 概述

海外发票和收据使用文档抽取接口。

```http
POST /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract
```

异步任务使用相同的请求体：

```http
POST /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract/create/task
GET /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract/query/task/{task_id}
```

## 请求参数

| 名称 | 类型 | 是否必填 | 描述 |
| --- | --- | --- | --- |
| `tenant_name` | string | 是 | 租户名称，默认 `laiye`。 |
| `app_id` | string | 是 | 预置应用标识。高速版（国际通用）为默认选项，也可选择东南亚版或标准版。 |
| `file_base64` | string | 可选 | 待抽取文件的 Base64，与 `file_url` 二选一。 |
| `file_url` | string | 可选 | 待抽取文件 URL，与 `file_base64` 二选一。仅支持 HTTP 开头的线上地址。 |
| `file_name` | string | 可选 | 文件名（含扩展名）。使用 Base64，或无法从 URL 判断文件名时传入。 |

## 版本选择

三个版本共用同一组同步和异步接口，仅通过 `app_id` 选择。

| 版本 | `app_id` | 说明 |
| --- | --- | --- |
| 高速版（国际通用） | `ootb_r3s6t9u2v5w8x1y4z7a0b3c6d9e2` | 默认选项，适用于国际通用的海外发票和收据。 |
| 东南亚版 | `ootb_u2v5w8x1y4z7a0b3c6d9e2f5g8` | 面向东南亚发票和收据，额外提供付款方国家、预扣税及行级预扣税字段。 |
| 标准版 | `ootb_a3f8h1j5k9n2p7q4w6x0y3b5c8d1` | 使用标准抽取方式处理海外发票和收据。 |
