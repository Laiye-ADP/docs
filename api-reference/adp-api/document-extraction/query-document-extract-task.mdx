sidebarTitle: 查询文档抽取任务结果
openapi: /api-reference/adp-api.yaml GET /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract/query/task/{task_id}
description: 查询单应用文档抽取异步任务的状态与结果。
---

使用[创建文档抽取异步任务](/api-reference/adp-api/document-extraction/create-document-extract-task)返回的 `task_id` 查询。任务完成后，响应包含实际使用的配置版本和应用配置的抽取字段。

[完整参数适用范围与原生文件示例](/api-reference/adp-api/document-extraction/extract-document)

任务status为0/1/2/4/5/6，分别为未知/就绪/运行中/成功/失败/取消或拒绝。海外发票多票返回可能同时包含tickets和按类型分组的extraction_result；它们表示同批结果，不要重复入账。
