---
title: 创建分类任务
description: 创建独立文档分类异步任务。
openapi: /api-reference/adp-api.yaml POST /open/agentic_doc_processor/{tenant_name}/v1/app/doc/classify/create/task
---

提交独立分类应用 `app_id` 和一个文件来源，接口立即返回 `task_id`；随后调用[查询分类任务](/api-reference/adp-api/document-classification/query-classification-task)获取任务状态和分类结果。
