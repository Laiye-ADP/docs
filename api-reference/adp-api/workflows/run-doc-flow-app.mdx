`application_id` 推荐使用已创建并发布的账号应用 ID。备选方式是传入工作流模板固定 ID：当前账号没有对应的可运行应用时，服务会自动创建并发布后运行，已有可运行应用时复用。

直接运行模板时省略 `release_version_id`。三个固定 ID 和请求示例见[业务工作流模板接入](/api-reference/adp-api/application-management/business-workflow-templates)。
