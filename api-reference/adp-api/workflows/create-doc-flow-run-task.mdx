除已发布账号应用 ID 外，`application_id` 也接受工作流模板固定 ID。当前账号没有对应的可运行应用时，服务会自动创建并发布后创建运行任务，已有可运行应用时复用。

直接运行模板时省略 `release_version_id`，通过返回的 `data.run_id` 查询结果。固定 ID 和请求示例见[业务工作流模板接入](/api-reference/adp-api/application-management/business-workflow-templates)。
