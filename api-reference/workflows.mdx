工作流应用用于把文档处理、业务判断、人工审核和结果交付等多个步骤组合成可重复运行的业务流程，适合单个抽取接口无法覆盖的多文档、多步骤或需要条件判断的场景。

<Warning>

</Warning>

## 创建并调用工作流

1. **选择创建方式**：使用已有业务工作流模板，或在 ADP 官方平台中通过 AI 对话助手创建自定义工作流。
2. **创建并发布应用**：官方模板可调用[从工作流模板创建应用](/api-reference/adp-api/application-management/create-workflow-application-from-template)，成功后即可运行；自定义工作流需在平台中测试并发布。
3. **获取应用 ID**：从模板创建的工作流应用使用创建接口返回的 `data.application_id`；在网站中创建并发布的应用使用“查询可运行的工作流应用”接口返回的 `id`。
4. **运行工作流**：根据是否需要等待结果，选择同步运行或创建异步任务；异步运行后可继续查询结果、重新运行或取消运行。

<Info>
  推荐按“查询模板 → 创建并发布工作流应用 → 上传文件并运行应用”的顺序接入。也可将模板固定 ID 作为 `application_id` 直接运行：当前账号没有对应的可运行应用时，服务会自动创建并发布后执行，已有可运行应用时复用。示例见[业务工作流模板接入](/api-reference/adp-api/application-management/business-workflow-templates)。需要修改工作流时，目前只能在 ADP 网站界面操作，测试并重新发布后再通过 OpenAPI 运行。
</Info>

从财务应付、费用报销和金融财报模板创建的应用共用本分组的运行接口。具体模板和接入示例见“应用管理”下的[业务工作流模板接入](/api-reference/adp-api/application-management/business-workflow-templates)。

## OpenAPI 能力

| 目标 | 接口 |
| --- | --- |
| 查询业务工作流模板 | `GET /open/agentic_engine/laiye/v1/app/templates` |
| 从工作流模板创建并发布应用 | `POST /open/agentic_engine/laiye/v1/app/applications/create-from-template` |
| 查询当前账号可运行的工作流应用 | `GET /open/agentic_engine/laiye/v1/app/applications` |
| 查询工作流应用详情（受限预览） | `GET /open/agentic_engine/laiye/v1/app/applications/{application_id}` |
| 同步运行工作流 | `POST /open/agentic_engine/laiye/v1/app/run` |
| 创建异步运行任务 | `POST /open/agentic_engine/laiye/v1/app/run/create/task` |
| 查询异步运行结果 | `GET /open/agentic_engine/laiye/v1/app/run/query/task/{run_id}` |
| 重新运行或取消运行 | `POST /open/agentic_engine/laiye/v1/app/run/{run_id}/rerun`、`POST /open/agentic_engine/laiye/v1/app/run/{run_id}/cancel` |

OpenAPI 当前可查询业务工作流模板，支持显式创建并发布应用，也支持直接使用模板固定 ID 自动创建或复用应用后运行。已发布应用可继续使用应用查询和运行管理能力。自定义工作流的创建、调整与发布需要在 ADP 官方平台中完成。
