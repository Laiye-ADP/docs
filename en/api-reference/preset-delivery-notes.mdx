## Overview

Get `app_id` from **View API** in the application or call [List applications](/en/api-reference/adp-api/application-management/list-applications) with `app_type=0` and `ai_function=1427`.

```http
POST /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract
```

Async task creation uses the same request body as synchronous extraction. Use the returned `data.task_id` to query the task. On success, the fields and line items are in `data.extraction_result`.

```http
POST /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract/create/task
GET /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract/query/task/{task_id}
```

## Request parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenant_name` | string | Yes | Tenant name. Default: `laiye`. |
| `app_id` | string | Yes | Unique ID of the preset application. View it in **View API**. |
| `file_base64` | string | Optional | Base64 content of the file. Use either `file_base64` or `file_url`. |
| `file_url` | string | Optional | Online file URL. Use either `file_url` or `file_base64`. Only HTTP URLs are supported. |
| `file_name` | string | Optional | File name. Provide it for Base64 input or when the name cannot be determined from the URL. |
| `enable_highlight` | boolean | No | Whether to show source locations for this extraction. |
| `enable_confidence` | boolean | No | Whether to calculate field confidence for this extraction. |
| `enable_field_value_translation` | boolean | No | Whether to translate field values for this extraction. Omit or pass `null` to use the saved application setting. |

Set the three switches at the top level of the request body. Use `true` to enable or `false` to disable an option for this extraction only. Omit a switch or pass `null` to use its saved application setting.

Extraction uses the fields saved in the application configuration. Source locations are shown by default. Confidence scores and field-value translation are off by default.
