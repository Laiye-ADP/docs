title: "Create an application from a workflow template"
sidebarTitle: "Create from a workflow template"
description: "Create and publish an accounts payable, expense reimbursement, or financial reporting workflow application for the current account and return its runnable application ID."
openapi: "/en/api-reference/adp-api.yaml POST /open/agentic_engine/laiye/v1/app/applications/create-from-template"
---

All three templates share this endpoint. Select a `template_key` to create and publish an application for the account associated with the current API key. If the account already has a corresponding runnable application, the endpoint reuses it. Repeated calls do not create another runnable copy for the same template.

Use the returned `data.application_id`, which identifies the account application, for file uploads, synchronous runs, or asynchronous run tasks. `data.template_version` is the version used by that application. Reusing an existing application preserves its version.

See [Integrate business workflow templates](/en/api-reference/adp-api/application-management/business-workflow-templates) for the complete flow. Workflow changes are currently available only through the [ADP website interface](https://adp-global.laiye.com/?utm_source=apidoc). Test and publish the modified application again before running it through OpenAPI.
