---
title: Publish extraction configuration
description: Publish a configuration version for a high-speed custom extraction application.
openapi: /en/api-reference/adp-api.yaml POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/version/publish
---

Provide `app_id` and optionally `config_version`. When the version is omitted, the latest unpublished version is published; publishing the same version again returns the same version information. Standalone classification applications do not use this endpoint.
