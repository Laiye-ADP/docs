sidebarTitle: Query document extraction result
openapi: /en/api-reference/adp-api.yaml GET /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract/query/task/{task_id}
description: Query the status and result of a single-application extraction task.
---

Use the `task_id` returned by [Create document extraction task](/en/api-reference/adp-api/document-extraction/create-document-extract-task). When processing completes, the response includes the configuration version used and the fields configured for the application.

[Parameter applicability and native-file examples](/en/api-reference/adp-api/document-extraction/extract-document)

Task status 0/1/2/4/5/6 means unknown/ready/running/success/failed/cancelled-or-rejected. Invoice multi-ticket results can include both tickets and type-grouped extraction_result, representing the same results; do not record them twice.
