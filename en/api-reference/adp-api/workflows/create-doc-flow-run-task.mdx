In addition to published account application IDs, `application_id` accepts fixed workflow template IDs. The service creates and publishes an account application before creating the run task if no corresponding runnable application exists, or reuses an existing one.

Omit `release_version_id` when running a template directly, then query the returned `data.run_id`. See [Integrate business workflow templates](/en/api-reference/adp-api/application-management/business-workflow-templates) for the fixed IDs and request example.
