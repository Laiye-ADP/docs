---
title: Create classification task
description: Create an asynchronous standalone document classification task.
openapi: /en/api-reference/adp-api.yaml POST /open/agentic_doc_processor/{tenant_name}/v1/app/doc/classify/create/task
---

Provide the standalone classification application `app_id` and one file source. The endpoint immediately returns a `task_id`; then use [Query classification task](/en/api-reference/adp-api/document-classification/query-classification-task) to retrieve the task status and result.
