ADP organizes document processing capabilities as applications. You can use system-provided ready-to-use applications or create custom extraction and workflow applications for your business.

<Columns cols={3}>
  <Card title="Ready-to-use applications" icon="sparkles">
    These applications include predefined fields and processing rules for common document scenarios. Select an application and use its `app_id` with the document extraction or recognition APIs.
  </Card>
  <Card title="Custom extraction applications" icon="sliders-horizontal">
    Define fields, table columns, labels, and extraction rules for your documents. The APIs in this section create, update, delete, and query applications and configuration versions.
  </Card>
  <Card title="Workflow applications" icon="network">
    Combine multiple processing steps for scenarios that require decisions, branches, or downstream actions. Use the APIs under Workflow to discover and run workflow applications.
  </Card>
</Columns>

<Note>
  The Create extraction application API creates custom extraction applications. Use the APIs under Application Management to discover business workflow templates and create and publish an application, then run it with the shared APIs under Workflow.
</Note>

</Info>

## Business workflow templates

Accounts payable, expense reimbursement, and financial reporting are workflow templates for reviewing document packages or splitting and consolidating financial reports. We recommend using [List business workflow templates](/en/api-reference/adp-api/workflows/list-business-workflow-templates) to obtain a `template_key`, then creating and publishing a workflow application.

Applications created from these templates share the synchronous run, asynchronous task creation, and result query APIs. Use the `application_id` returned by creation. See [Integrate business workflow templates](/en/api-reference/adp-api/application-management/business-workflow-templates) for the template catalog, file preparation, and request example.

To add a template application for the current account, use [Create an application from a workflow template](/en/api-reference/adp-api/application-management/create-workflow-application-from-template). The endpoint creates and publishes an application, or reuses the corresponding runnable application if one already exists.

Alternatively, pass a fixed template ID as `application_id` to the synchronous or asynchronous run endpoint. The service creates and publishes an account application if no corresponding runnable application exists, or reuses an existing one. See [Integrate business workflow templates](/en/api-reference/adp-api/application-management/business-workflow-templates) for the fixed IDs and request example.

Workflow changes are currently available only through the [ADP website interface](https://adp-global.laiye.com/?utm_source=apidoc). Test and publish the modified application again before running it through OpenAPI.

## Common management operations

| Operation | Endpoint |
| --- | --- |
| Create a custom extraction application | `POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/create` |
| List applications | `GET /open/agentic_doc_processor/{tenant_name}/v1/app-list` |
| List business workflow templates | `GET /open/agentic_engine/laiye/v1/app/templates` |
| Create and publish an application from a workflow template | `POST /open/agentic_engine/laiye/v1/app/applications/create-from-template` |
| Update or delete an application | `POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/update`, `POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/delete` |
| Query or delete a configuration version | `POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/config`, `POST /open/agentic_doc_processor/{tenant_name}/v1/app-manage/version/delete` |
