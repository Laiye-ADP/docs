## Overview

Domestic general bills use the document extraction API.

```http
POST /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract
```

The API returns extracted fields and classification results based on the preset application configuration. To include invoice verification in the current extraction, pass `enable_invoice_verify: true`. If omitted, the saved application setting is used.

For large files or longer-running extractions, create an asynchronous task first and use its `task_id` to query the result:

```http
POST /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract/create/task
GET /open/agentic_doc_processor/{tenant_name}/v1/app/doc/extract/query/task/{task_id}
```

To verify an invoice directly from its invoice details, call the standalone invoice verification API:

```http
POST /open/agentic_doc_processor/{tenant_name}/v1/app/invoice/verify
```

The API supports 11 invoice types. `fpNumber` and `fpDate` are common required fields, while other fields are conditionally required by `type_key`. Existing three-field requests can continue to omit `type_key`; they are handled as `vat_electronic_invoice_new` and must include `fpAmount`. Use `YYYY-MM-DD` for the date.

HTTP 200 with `code=success` means that the API completed processing. Read `data.result.fpVerification` to determine whether the invoice passed verification. See the standalone endpoint page for the required-field matrix, request examples, and response schema.

## Request parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `tenant_name` | string | Yes | Tenant name. Default: `laiye`. |
| `app_id` | string | Yes | Unique ID of the domestic general bill preset application. |
| `file_base64` | string | Optional | Base64 content of the file. Use either `file_base64` or `file_url`. |
| `file_url` | string | Optional | Online file URL. Use either `file_url` or `file_base64`. Only HTTP URLs are supported. |
| `file_name` | string | Optional | File name. Provide it for Base64 input or when the name cannot be determined from the URL. |
| `enable_invoice_verify` | boolean | Optional | Whether this extraction includes invoice verification. `true` enables it and `false` disables it; omit the field to use the saved application setting. Only applies to the domestic general bill application. |

## Example

This example extracts a file from a URL and enables invoice verification for this request:

```bash
curl --request POST \\
  'https://adp.laiye.com/open/agentic_doc_processor/laiye/v1/app/doc/extract' \\
  --header 'Content-Type: application/json' \\
  --header 'X-API-KEY: YOUR_API_KEY' \\
  --data '{
    "app_id": "ootb_v9x2y5z8a1b4c7d0e3f6h9j1k4m7",
    "file_url": "https://your-accessible-url/invoice.pdf",
    "enable_invoice_verify": true
  }'
```
